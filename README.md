# Tips_SE — 演劇用ポン出しアプリ

ONJO に次ぐ、本番で「落ちない・遅れない・確実に鳴る」ことを目指した効果音ポン出しアプリ。

## ONJO の弱点と本アプリの対策

| ONJO の弱点 | 本アプリの対策 |
|------------|----------------|
| 再生に約2秒のラグ | 全音源を起動時に **PCM へ事前デコードして RAM 常駐**。再生はメモリコピーのみ＝実測でキー押下→発音 約5ms |
| 再生されない取りこぼし | **WASAPI 出力ストリームを開きっぱなし**にし、ソフトミキサーにサンプルを流すだけ。再生ごとにデバイスを開閉しない |
| 長時間で不安定・落ちる | 再生のたびにオブジェクトを生成/破棄しない設計でリークを排除 |

（調査の詳細は [01_onjo調査と設計方針.md](01_onjo調査と設計方針.md) を参照）

## 起動方法
- **配布版アプリ**: `Tips_SE (アプリ起動).lnk`（ショートカット）または
  `dist\Tips_SE\Tips_SE.exe` をダブルクリック。Python不要で単独動作します。
- **開発時（ソースから）**: `起動.bat` をダブルクリック。

## exe のビルド（再ビルド方法）
1. `ビルド.bat` をダブルクリック（内部で PyInstaller が走る）
2. 完成物は `dist\Tips_SE\` フォルダ。**このフォルダごと**配布・コピーすれば
   どのWindows PCでもPythonなしで動作します（onedir形式 / コンソール非表示）。
3. PortAudio・libsndfile・soxr のネイティブDLLは自動で同梱されます（`Tips_SE.spec`）。

### ログ / トラブル時
コンソール非表示ビルドのため、エラーは次のログに記録されます:
`%LOCALAPPDATA%\Tips_SE\tips_se.log`

## 使い方
- **空パッドをクリック** → 音源ファイルを割り当て
- **割当済みパッドをクリック** → 再生／もう一度クリックで停止（トグル）
- **割当キー押下** → 再生（連打で重ね鳴らし＝SFX向け）
- **各パッド下のフェーダー** → そのパッドの音量を個別調整（再生中は即時反映）
- **右クリック** → 再生 / 停止 / 設定 / クリア
- **Space または Esc** → 全停止（フェードアウト付き）
- **マスター音量スライダー** → 全体音量
- **各パッドの番号** → 左上に表示（戯曲スタンプの参照番号と一致）
- **右端のレベルメーター** → 出力音量を音響卓風に表示（L+R統合、dB目盛り、ピークホールド、クリップLED）
- メニュー「ファイル」→ プリセット保存/読込、フォルダから一括割当
- メニュー「グリッド」→ 行・列数の変更（最大 8×8 = 64）

### パッド設定（右クリック→設定）
- 音源ファイル / 表示名 / 割当キー（1文字）
- 音量、フェードイン、フェードアウト
- ループ再生、排他再生（鳴らすと他の音を止める）

## 戯曲PDFビューア（台本を見ながら音響操作）
中央〜右の戯曲パネルで、台本PDFを見ながら音を出せます。

- **「戯曲PDFを開く…」**（パネル上部 / メニュー「戯曲」）→ 台本PDFを表示
- **マウスホイールで上下に連続スクロール**（全ページが縦に繋がって表示されます）
- **◀ ▶** で前後ページの先頭へジャンプ、**－ ＋**（または Ctrl+ホイール）でズーム
- **本番モード**: PDF上のスタンプをクリックすると、その番号のパッドが鳴る
  （台本を目で追いながら、きっかけの場所をクリックするだけで音出し）

### 編集モード（上部「✎ 編集モード」）
台本に音出しのきっかけを書き込めます。保存するとプリセットに含まれます。
- **● スタンプ**: 「スタンプ番号」を選び、PDF上をクリック → 「この箇所で○番を流す」印を配置
- **▭ テキスト**: PDF上をクリック → 付箋メモ（きっかけ・注意書き）を記入
- 配置した注釈は **ドラッグで移動**、**選択して Delete で削除**

## 対応音源フォーマット
wav / flac / mp3 / ogg / aiff / w64 など（libsndfile 対応形式）。
※ m4a/aac は現状未対応（今後 ffmpeg フォールバックで対応予定）。本番は wav 推奨。

## 読み込みの軽さ（フリーズ対策）
音源の読み込み（フォルダ一括割当・プリセット読込）は**バックグラウンドで並列実行**され、
UIは一切固まりません。各パッドは「⏳ 読み込み中…」表示→完了で使用可能になります。
リサンプルは高品質・高速な **soxr** を使用（未導入時は線形補間にフォールバック）。
