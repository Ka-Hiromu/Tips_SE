# Tips_SE — 演劇用ポン出しアプリ

ONJO に次ぐ、本番で「落ちない・遅れない・確実に鳴る」ことを目指した効果音ポン出しアプリ。

## ONJO の弱点と本アプリの対策

| ONJO の弱点 | 本アプリの対策 |
|------------|----------------|
| 再生に約2秒のラグ | 全音源を起動時に **PCM へ事前デコードして RAM 常駐**。再生はメモリコピーのみ＝キー押下→発音 約20ms（ONJOの2秒に対し体感即時）|
| 再生されない取りこぼし | **WASAPI 出力ストリームを開きっぱなし**にし、ソフトミキサーにサンプルを流すだけ。再生ごとにデバイスを開閉しない |
| 長時間で不安定・落ちる | 再生のたびにオブジェクトを生成/破棄しない設計でリークを排除 |

（調査の詳細は [01_onjo調査と設計方針.md](01_onjo調査と設計方針.md) を参照）

## 起動方法
- **`Tips_SE起動.exe`**（または `Tips_SE (アプリ起動).lnk`）をダブルクリック
  → 同フォルダの `.venv` でソース(`src/main_app.py`)を起動。**`起動.bat` と同じ挙動**で
  常に最新コード・全機能で動作（コンソール窓なし）。要 `.venv` と `src`。
- **`起動.bat`**：上と同じ（バッチ版）。
- **単独動作版**: `dist\Tips_SE\Tips_SE.exe`（Python不要で配布できる版）。

> `Tips_SE起動.exe` は `launcher.py` を PyInstaller でビルドしたもの。再ビルドは:
> `.venv\Scripts\pyinstaller --onefile --windowed --name TipsSELauncher launcher.py`
> → 生成された `TipsSELauncher.exe` を `Tips_SE起動.exe` にリネームして直下に配置。

## exe のビルド（再ビルド方法）
1. `ビルド.bat` をダブルクリック（内部で PyInstaller が走る）
2. 完成物は `dist\Tips_SE\` フォルダ。**このフォルダごと**配布・コピーすれば
   どのWindows PCでもPythonなしで動作します（onedir形式 / コンソール非表示）。
3. PortAudio・libsndfile・soxr のネイティブDLLは自動で同梱されます（`Tips_SE.spec`）。

### ログ / トラブル時
コンソール非表示ビルドのため、エラーは次のログに記録されます:
`%LOCALAPPDATA%\Tips_SE\tips_se.log`
終了時に `underflow=N` を記録します（出力アンダーラン回数）。長尺BGMでノイズが出る場合の
目安で、0 が理想。増える場合は `engine.AudioEngine` の `blocksize` を大きくしてください。

### exe が消える / 起動ショートカットが死ぬ場合
未署名でネットワーク機能（スマホ操作）を持つため、Windowsセキュリティ（Defender）が
ビルド直後の `Tips_SE.exe` を削除してしまうことがあります（ショートカットの実体が消える）。
対処:
1. `Windowsセキュリティ除外.bat` をダブルクリック（UACで許可）→ `dist` フォルダを除外に追加
2. `ビルド.bat` で再ビルド → exe が消えずに生成される
3. `Tips_SE (アプリ起動).lnk` が再び使えます
※ ビルドが途中で乱れた時は `build` と `dist\Tips_SE` を削除してから `ビルド.bat`（クリーンビルド）。

### 確率（ランダム再生）の自動補完
確率モードで各音源の % を入力する際、**1つだけ空欄**にして OK すると、
残り（100 − 入力済みの合計）が自動で補完されます。全部空欄なら等確率になります。

## 使い方
- **空パッドをクリック** → 音源ファイルを割り当て
- **割当済みパッドをクリック** → 再生／もう一度クリックで停止（トグル）
- **割当キー押下** → 再生／同じキーをもう一度押すと停止（トグル）。キーは各パッドに大きく薄く表示
- **各パッド下のフェーダー** → そのパッドの音量を個別調整（再生中は即時反映）
- **右クリック** → 再生 / 停止 / 設定 / クリア
- **Space または Esc** → 全停止（フェードアウト付き）
- **マスター音量スライダー** → 全体音量
- **各パッドの番号** → 左上に表示（戯曲スタンプの参照番号と一致）
- **パッド下部の記号表示** → 有効な機能だけが決まった位置に出る。
  左に **⟳**（ループ）/ **EXCL**（排他）/ **連**（連続再生）/ **範**（再生範囲あり）、右に **◢ 秒数**（フェードイン）/ **◣ 秒数**（フェードアウト）。
  フェード進行中は、進んでいる側の記号が白く光る
- **画面右下の 🔊 表示** → いま音を出している出力デバイス名を常時表示
- **右端のレベルメーター** → 出力音量を音響卓風に表示（L+R統合、dB目盛り、ピークホールド、クリップLED）
- メニュー「ファイル」→ プリセット保存/読込、フォルダから一括割当
- メニュー「グリッド」→ 行・列数の変更（最大 8×8 = 64）

### パッド設定（右クリック→設定）
- 音源ファイル / 表示名 / 割当キー（1文字）
- 音量、フェードイン、フェードアウト
- **再生範囲**（再生開始 / 再生終了, 秒）… 音源の一部だけを鳴らす。
  両方0なら全体。読み込み時にその範囲だけをRAMへ常駐させるので、再生時のコストは
  ゼロ（長尺の一部だけ使う場合はメモリも節約になる）。変更すると読み直しが走る
- ループ再生、排他再生（鳴らすと他の音を止める）

## 📱 スマホからのリモート操作（クロスフェード）
マウスでは一度に1つのフェーダーしか動かせずクロスフェードができないため、
スマホの指で複数フェーダーを同時操作できるリモート機能を用意。
1. メニュー「コンフィグ」→ **「スマホ操作」** をON（既定OFF）→ ツールバーに現れた
   **「📱 スマホ操作」** をON → **QRコード**とURLが表示される
2. **同じWi-Fi** につないだスマホのカメラ/ブラウザでQRを読み取る（URL直接入力も可）
3. **再生中の音だけ**が縦フェーダー（目盛付き）で並ぶ → 指で**同時に音量調整＝クロスフェード**
- 横画面向けの最小レイアウト（フェーダー＋番号.名前のみ、左上にオンライン表示）。PC側と双方向同期。
- ローカルネットワーク内でのみ動作（インターネット公開なし）。新規依存なし（Qtの内蔵サーバを使用）。

## コンフィグ（拡張機能）
メニュー「コンフィグ」で拡張機能をON/OFFできます（設定はアプリに保存）。

### ランダム再生
ONにすると、パッド設定（右クリック→設定）に **「確率」** チェックボックスが出現します。
- 「確率」を有効にすると、**1つのボタンに複数の音源**を登録でき、再生時にどれか1つが**ランダム**に鳴ります。
- 各音源に**確率(%)**を設定（合計100%）。初期は等確率。**1つだけ空欄**にしてOKすると残りを**自動補完**。
- 確率配分は**小さな円グラフ**で確認できます。

### スマホ操作（既定OFF）
本番中はまず使わない機能なので、既定ではツールバーに出しません。
ONにすると **「📱 スマホ操作」** ボタンが現れます。
（戯曲PDFの表示・編集モードの切替はメニュー **「戯曲」** にあります）

### フェード秒数を表示（既定ON）
OFFにすると、パッドのフェード表示がアイコン（◢ ◣）だけになります。

## 音量について
全体出力は最終的に **0.95倍**にトリムしている（出しすぎ防止）。`engine.AudioEngine.output_trim` で調整可。

## 戯曲PDFビューア（台本を見ながら音響操作）
中央〜右の戯曲パネルで、台本PDFを見ながら音を出せます。

- **「戯曲PDFを開く…」**（パネル上部 / メニュー「戯曲」）→ 台本PDFを表示
- **マウスホイールで上下に連続スクロール**（全ページが縦に繋がって表示されます）
- **◀ ▶** で前後ページの先頭へジャンプ、**－ ＋**（または Ctrl+ホイール）でズーム
- **本番モード**: PDF上のスタンプをクリックすると、その番号のパッドが鳴る
  （台本を目で追いながら、きっかけの場所をクリックするだけで音出し）

### 編集モード（メニュー「戯曲」→「編集モードを使う」をONにすると上部にボタンが出ます）
台本に音出しのきっかけを書き込めます。保存するとプリセットに含まれます。
- **● スタンプ**: 「スタンプ番号」を選び、PDF上をクリック → 「この箇所で○番を流す」印を配置
- **▭ テキスト**: PDF上をクリック → 付箋メモ（きっかけ・注意書き）を記入
- 配置した注釈は **ドラッグで移動**、**選択して Delete で削除**

## ONJO のリスト(.lst)を読み込む
ONJO で作った `.lst` をそのまま開けます。

- 「ファイル」→**「プリセットを開く…」**（`*.lst` も選べます）、または
  「ファイル」→**「ONJOのリストを取り込む…」**
- 取り込み後に、取り込めなかった設定の一覧が出ます（「詳細を表示」で全件）。
- **元の `.lst` は書き換えません**。保存すると Tips_SE のプリセット(.json)になります。

| ONJO 側 | Tips_SE での扱い |
|---|---|
| ﾎﾞﾘｭｰﾑ | パッド音量（0.0-1.5 に収めて取り込み） |
| 繰り返し | ループ再生 |
| 他の音を全て止める | 排他再生 |
| ﾌｪｰﾄﾞｲﾝ / ﾌｪｰﾄﾞｱｳﾄ | ON のとき **2.0秒**（ONJOはフェード長を`.lst`に保存しないため既定値） |
| キー | 1文字キー（数字・英字・記号・テンキー）はそのまま。Enter・スペース・矢印・F1〜F12・修飾キーは**取り込めない**ので空にして警告 |
| 1プレイヤーに複数音源 | コンフィグの「ランダム再生」ON なら**確率（均等）**で全部、OFF なら先頭だけ（ONJOの順番どおりの連続再生は未対応） |
| 再生範囲 | パッドの「再生開始/再生終了」へそのまま取り込み（範囲が逆のときは終了側を無視して警告） |
| プレイヤー番号 | パッド番号としてそのまま維持（グリッドは自動で必要な行×列に） |

音源が見つからないときは、`.lst` と同じフォルダ以下を**ファイル名で探して自動で差し替え**ます
（ONJO は音源を絶対パスで持つため、フォルダを移した `.lst` でもそのまま鳴ります）。

## 対応音源フォーマット
wav / flac / mp3 / ogg / aiff / w64 など（libsndfile 対応形式）。
※ m4a/aac は現状未対応（今後 ffmpeg フォールバックで対応予定）。本番は wav 推奨。

## 読み込みの軽さ（フリーズ対策）
音源の読み込み（フォルダ一括割当・プリセット読込）は**バックグラウンドで並列実行**され、
UIは一切固まりません。各パッドは「⏳ 読み込み中…」表示→完了で使用可能になります。
リサンプルは高品質・高速な **soxr** を使用（未導入時は線形補間にフォールバック）。

Python 3.11 / sounddevice(PortAudio+WASAPI) / soundfile / soxr / numpy /
